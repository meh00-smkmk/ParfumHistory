# PerfumierPro customer scent history

> A QR-friendly customer-history page for perfume retailers that turns POS purchase data into a useful repeat-visit experience.

## The problem it solves

Retail staff need a simple way to recover a returning customer’s purchase history without manually searching through receipts or a separate customer database.

## Who it is for

Independent perfume shops and retail teams that want a lightweight customer-service companion for a POS workflow.

## Key features

- Displays a customer’s previously purchased perfumes and quantities
- Uses a URL-safe encoded data payload, making it suitable for a QR-code link on a receipt
- Adapts the page title and shop/customer labels from the payload
- Handles incomplete or invalid links with a clear recovery message
- Runs entirely in the browser; no API key or third-party AI service is required

## Run locally

```bash
git clone https://github.com/mahboubi-younes/ParfumHistory.git
cd ParfumHistory
```

Open `public-history/index.html` in a modern browser. The page expects a `?data=` URL parameter generated by its POS companion.
